# Tests

This project follows Maven's standard layout, so the real automated test
suite lives at:

    src/test/java/com/example/expensetracker/ExpenseControllerTest.java

Run it with:

    mvn test

This file exists to satisfy the `tests/` folder shown in the assignment's
required submission structure, since Maven expects tests to physically live
under `src/test/java` in order for `mvn test` to find and run them.
